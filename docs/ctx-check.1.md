# ctx-check(1)

## NAME

ctx-check - CTX OS System Health Check

## SYNOPSIS

**ctx-check**

## DESCRIPTION

ctx-check performs a series of checks on the CTX OS system to verify health and status, including command availability, disk usage, memory usage, and service status.

## EXIT CODES

- **0** — All health checks passed
- **1** — Some health checks failed or had warnings

## SEE ALSO

ctx-config(1), ctx-update(1)
