# ctx-config(1)

## NAME

ctx-config - CTX OS Configuration Manager

## SYNOPSIS

**ctx-config** [*COMMAND* [*OPTIONS*]]

## DESCRIPTION

ctx-config reads and manages CTX OS configuration files.

## COMMANDS

- **show KEY** — Show configuration value for KEY
- **set KEY VALUE** — Set configuration value for KEY
- **list** — List all configuration values
- **reset** — Reset all configuration to defaults

## FILES

- `/etc/ctx/*.conf` — Configuration files

ctx-update(1), ctx-about(1)
